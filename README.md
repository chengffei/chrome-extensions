# chrome-extensions

Felix 自制的 Chrome 插件合集，Chrome 与夸克等 Chromium 浏览器通用。每个插件一个目录，互不依赖。

| 插件 | 说明 |
| --- | --- |
| [Lodestone 磁石](lodestone/) | 列出网页里的磁力链接和哈希，推测资源名，一键复制和定位 |

## 安装

1. 下载或 clone 本仓库
2. 打开 `chrome://extensions`（夸克用 `quark://extensions`），开启「开发者模式」
3. 点「加载已解压的扩展程序」，选对应插件的目录
